# Denver Dustless Floor Leveling — Website

Static multi-page site (no build step). Drag the contents of this folder into a GitHub repo and enable **Settings > Pages > Deploy from branch** to host for free.

## Before launch — replace these placeholders
- **Formspree**: in `contact.html`, change `action="https://formspree.io/f/YOUR_FORM_ID"` to your real form ID.
- **Phone**: `(XXX) XXX-XXXX` (contact.html)
- **Email**: `hello@denverdustless.com` (contact.html)
- **Photos**: gallery tiles in `gallery.html` and the "Project Photo" block in `services.html`.

## Files
index.html, services.html, gallery.html, about.html, contact.html, styles are inlined per page, plus logo-white.png / logo.png.
