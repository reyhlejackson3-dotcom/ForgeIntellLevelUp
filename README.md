# Denver Dustless Floor Leveling - Website

Static multi-page site (no build step, no dependencies). Wood-textured background, stone top bar, static mountain scenes with slow drifting clouds and mist.

## Host on GitHub Pages
1. Create a repo and drag in every file from this folder (keep them at the repo root).
2. Settings > Pages > Deploy from branch > main / root.

## Before launch - replace these placeholders
- Formspree: in contact.html, change action="https://formspree.io/f/YOUR_FORM_ID" to your real form ID.
- Phone: (XXX) XXX-XXXX (contact.html)
- Email: hello@denverdustless.com (contact.html)
- Photos: gallery tiles in gallery.html and the "Project Photo" blocks in index.html / services.html.
